# Аудит случайного веба

Задача браузера — открывать **любой** сайт, а не три памятника. Этот прогон
берёт случайную выборку из широкого списка (60+ сайтов, категории: новости,
доки, магазины, SPA, форумы, гос, простые) и показывает, где движок стоит
на самом деле.

## Как гонять

```bash
python3 scripts/web-audit.py                     # 8 случайных
python3 scripts/web-audit.py --count 12 --seed 7 # повторяемая выборка
python3 scripts/web-audit.py --sites yandex google youtube
python3 scripts/web-audit.py --no-visual         # только текст/ссылки/время
```

Отчёт: `/tmp/sepia-web-audit/report.json`, композиты по сайтам рядом.
Закреплённые эталоны (`docs/qa/reference/*.png`) приоритетнее свежего Chrome:
headless-Chrome нестабилен (HN отдаёт пустую страницу из-за лимитов,
Wikipedia — с баннером).

## Что это значит

Сильная сторона: статичные доки/лендинги (rust-lang, docs.rs, example) —
там движок уже на 80+. Слабая:

1. **Тёмная тема** (MDN 24, vercel 28): сайт красит фон через CSS-переменные
   и `color-scheme`, а у нас остаётся белый лист. Механизм: var() + тёмные
   значения + `prefers-color-scheme`.
2. **Вёрстка современных лендингов** (vercel): нелинейные сетки, крупные
   заголовки, градиенты.
3. **Скорость**: 5 сайтов из 8 медленнее 20 с.
4. **Пустые ответы** (airbnb: 0 узлов): похоже на блокировку автоматике —
   нужна страница-объяснение, а не пустота.

## Уточнение про DDG (18.11, позднее)

Первый замер DDG 13.6 был артефактом сравнения: наш движок следует системной
тёмной теме (macOS Dark), а headless-Chrome всегда светлый — DDG рисовался
у нас тёмным, у Chrome светлым. Теперь оба снимаются в светлой теме.

Но и после этого DDG честно низкий: **10–13**. Причина не в теме:

- `lite.duckduckgo.com` отдаёт Chrome полную выдачу с JS, а без JS шлёт на
  lite-версию — сравниваются **разные страницы**. Для честного сравнения нужен
  `html.duckduckgo.com/html/` (без-JS версия).
- На `/html/` у нас **2.3**: страница рисуется голым текстом (строки стран,
  ссылки), блоки выдачи с рамками и фоном — нет. ink 2.9% против 26.6%.
  Это реальная дыра вёрстки: result-блоки на float/рамках.

Вывод для движка: (1) `noscript`-редиректы — отдельный механизм: при JS
выкл/отсутствии выбирать no-JS версию и сравнивать с той же; (2) вёрстка
страниц с float-блоками и рамками у нас отсутствует.

## Правило

Новая правка движка проверяется не на «своих» сайтах, а на свежей случайной
выборке (`--seed` фиксируется в отчёте). Если механизм общий — медиана
поднимается; если латка — нет.
