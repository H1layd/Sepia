# Спецификация: браузер как браузер

Цель этапа: **обычный браузер**. Не «Sepia с приколами», не исследовательский
движок с собственным UX, а инструмент, который открывает сайты и ведёт себя
предсказуемо для человека, привыкшего к Chrome/Firefox/Safari. Анонимность,
безопасность, профили и маршруты — следующий этап, моя часть. Здесь их нет.

Главное правило: **если стандартное поведение спорит с нашей выдумкой —
побеждает стандарт**. Своя панель вместо вкладок, свой док вместо адресной
строки, авто-переключение на чужой движок, персоны, подмена языка — всё это
на этапе «просто браузер» выключено.

## 0. Что считается «готово»

Браузер готов, когда человек без инструкции:

1. открывает его, видит строку адреса и вкладку;
2. вводит адрес или запрос — попадает на сайт или в поиск;
3. ходит по ссылкам, назад/вперёд, обновляет;
4. открывает несколько сайтов в разных вкладках;
5. пользуется формами: вводит, отправляет, получает результат;
6. скачивает файл и находит его на диске;
7. смотрит видео на YouTube;
8. и не встречает чёрных экранов, пустых страниц и кнопок, которые не нажимаются.

## 1. Окно и управление

- **Вкладки**: полоса сверху, создать (+), закрыть (×), переключить, перетащить,
  заголовок и иконка сайта, индикатор загрузки. `⌘T`, `⌘W`, `⌘1…9`, `⌘⇧T`
  (восстановить закрытую).
- **Адресная строка**: ввод адреса, поиск при вводе не-адреса, автодополнение
  из истории (хотя бы по префиксу), выделение всего по фокусу, `⌘L`.
- **Кнопки**: назад, вперёд, обновить, остановить, домой. Состояния
  disabled, когда некуда.
- **Меню**: новая вкладка, история, закладки, скачивания, настройки, выход.
  Никаких «Персона/Профили/Трафик/Сжечь» в этом меню.
- **Поиск по странице** `⌘F` с подсветкой и счётчиком.
- **Масштаб** `⌘+`, `⌘-`, `⌘0` — влияет на текст и раскладку.
- **Полный экран** `⌃⌘F`, **обновить** `⌘R`, **стоп** `Esc`.
- **Контекстное меню** правой кнопкой: назад/вперёд/обновить, открыть ссылку
  в новой вкладке, копировать адрес ссылки, сохранить картинку, копировать/
  вставить, выделить всё.
- Окно: изменение размера без перезагрузки, запоминание размера, retina.

## 2. Навигация

- Разбор URL: `http`, `https`, `file`, `about:blank`, `data:`, якоря,
  IDN (кириллические домены), percent-encoding.
- HTTP: 200/301/302/303/307/308, заголовки, cookies (механизм — есть),
  keep-alive, gzip/br, таймауты, редиректы (лимит), basic auth (диалог или
  понятная ошибка).
- История: назад/вперёд по переходам, `pushState`/`replaceState`/`popstate`,
  переход по `#якорю` без перезагрузки, сохранение позиции прокрутки.
- Ошибки: понятная страница с кодом и кнопкой «повторить» для DNS-сбоя,
  таймаута, 4xx/5xx, TLS-ошибки. Никаких пустых экранов.
- Скачивание по клику: если ответ — файл (`Content-Disposition` или
  не-HTML тип), начинается загрузка, а не пустая вкладка.

## 3. Рендеринг (то, что видит человек)

Приоритет — «как в оригинале», а не «текст кое-как».

- **HTML**: дерево по спеке, неявные теги, таблицы (включая `colspan/rowspan`),
  формы, списки, `<template>`, `<svg>` (базово), `<img>` c `srcset` (хотя бы
  выбор одного).
- **CSS-бокс**: margin collapsing, padding, border, `box-sizing`, `width/height`
  включая `%`/`calc`, `min/max`, `overflow` (visible/hidden/scroll/auto).
- **Позиционирование**: `static`, `relative`, `absolute`, `fixed`, `sticky`.
  Sticky — обязательно (шапки Wikipedia и GitHub).
- **Многоколоночность**: `float`, `clear`, `display: flex` (row/column, wrap,
  justify, align, gap), `display: grid` (колонки/строки, `fr`, `minmax`,
  `auto-fill`, `grid-area`, `span`). Сайдбар и инфобокс Wikipedia, About
  GitHub — это проверка.
- **Таблицы**: `display: table`, `table-row`, `table-cell`, фиксированные и
  авто-ширины, выравнивание. Список файлов GitHub — проверка.
- **Шрифты**: системные семейства, `@font-face` (ttf/otf/woff/woff2),
  `font-size/weight/style`, `line-height`, `letter-spacing`, наследование,
  fallback по codepoint, эмодзи. Метрики должны совпадать с оригиналом:
  одинаковая ширина строки при одинаковом тексте и кегле.
- **Цвета**: наследование, `currentColor`, `rgba/hsl`, `color-scheme`
  (тёмная тема сайта), CSS-переменные `var()`, `opacity`.
- **Фоны и оформление**: цвет, картинки (`background-size/position/repeat`),
  градиенты, `border-radius`, тени, `outline`.
- **Текст**: переносы по словам, `white-space`, `text-transform`,
  `text-decoration`, `text-align`, списки с маркерами, цитаты, код,
  базовая двунаправленность (RTL хотя бы не ломает арабский/иврит).
- **Медиа-запросы**: `min/max-width`, `prefers-color-scheme`,
  `prefers-reduced-motion`, `hover`, `pointer`.
- **Анимации**: CSS transitions/animations — хотя бы не ломать раскладку;
  JS-анимации через `requestAnimationFrame`.
- **Выделение и каретка**: выделение мышью и клавиатурой, копирование,
  каретка в полях, скролл к курсору.

## 4. JavaScript

Не «всё подряд», а тот минимум, без которого сайты — оболочка.

**Язык**: ES2020: let/const, классы, стрелки, шаблоны, деструктуризация,
spread, async/await, generators, Symbol, Proxy (хотя бы базово), BigInt,
опциональная цепочка, `?.`/`??`.

**DOM**: `querySelector(All)`, `getElementById`, `createElement`, `append`,
`remove`, `classList`, `dataset`, `setAttribute/getAttribute`, `innerHTML`,
`textContent`, `cloneNode`, `replaceWith`, `insertAdjacentHTML`, `children`,
`parentElement`, `nextElementSibling`, `matches`, `closest`, `getBoundingClientRect`,
`offsetWidth/Height`, `scrollTop/Left`, `scrollIntoView`.

**События**: `addEventListener` (bubble/capture, once, passive), `dispatchEvent`,
`preventDefault`, `stopPropagation`, `MouseEvent/KeyboardEvent/InputEvent/
SubmitEvent/FocusEvent/CustomEvent`, `DOMContentLoaded`, `load`, `resize`,
`scroll`, `visibilitychange`, `hashchange`, `popstate`.

**Сеть**: `fetch` (GET/POST/JSON/заголовки/AbortController), `XMLHttpRequest`
(хотя бы базово), cookies (document.cookie), same-origin политика (CORS —
честно: разрешать same-origin, для остального — отказ с внятной ошибкой).

**Хранилища**: `localStorage`, `sessionStorage`, `history`, `location`,
`URL`, `URLSearchParams`, `JSON`, `Promise`, `setTimeout/setInterval`,
`requestAnimationFrame`, `performance.now`, `performance.timing`/`getEntries`
(заглушка лучше падения).

**Платформа**: `customElements`, `HTMLElement` классы, `MutationObserver`,
`IntersectionObserver`, `matchMedia`, `getComputedStyle`, `document.forms`,
валидация полей, `FormData`, `File`/`Blob` (чтение), `TextEncoder`,
`crypto.getRandomValues`, `Intl` (даты/числа).

**Что можно не делать сейчас** (но признать честно): WebSocket, Worker,
ServiceWorker, IndexedDB, WebGL/Canvas 2D, WebRTC, notifications,
geolocation, clipboard API (кроме copy по кнопке).

**Диагностика**: `--js-log` должен печатать исключения с файлом/строкой, а не
молчать. Без этого чинить JS — гадание.

## 5. Формы

Текст, `textarea`, `select`/`option`, `checkbox`, `radio`, `range`, `file`
(через диалог), `submit`, `reset`, `label` (клик по подписи), `disabled`,
`readonly`, `required`, `pattern`, `placeholder`, `autofocus`, Enter в поле =
отправка, GET и POST (`application/x-www-form-urlencoded`; multipart — для
файлов), скрытые поля, кнопки с `formaction`. Проверка: поиск на сайте,
вход в форму, фильтры.

## 6. Вкладки и сессия

- Каждая вкладка: свой URL, история, прокрутка, скрипты, заголовок, иконка.
- Создание/закрытие/переключение/перестановка, `⌘T/⌘W/⌘1…9`.
- Закрытая вкладка восстанавливается `⌘⇧T` (после этого этапа, но заложить).
- Восстановление сессии при запуске — по настройке, по умолчанию выкл.
- Фоновая вкладка не должна жрать CPU (таймеры — с ограничением).

## 7. Скачивания

Клик по файлу → загрузка с прогрессом в интерфейсе, список загрузок,
«показать в папке», отмена. Имена и коллизии — как у людей (`file (1).zip`).
Сохранение страницы (`⌘S`), сохранение картинки из контекстного меню.

## 8. Медиа

- `<video>`/`<audio>`: H.264/AAC и VP9/Opus (через системные кодеки или
  встроенный декодер — решение за тобой), звук, пауза, перемотка, громкость,
  полный экран, `poster`.
- YouTube: страница и плеер как в обычном браузере. Если это невозможно
  в текущем движке — честная страница «сайт требует полного движка» с
  объяснением, но не пустой экран.
- Автовоспроизведение: только по действию пользователя.

## 9. Настройки

Домашняя страница, поисковик по умолчанию, папка загрузок, тема
(светлая/тёмная/системная), язык интерфейса, масштаб по умолчанию,
очистка данных, «восстанавливать сессию». Ничего про анонимность и профили.

## 10. Производительность (бюджеты, а не пожелания)

| Что | Бюджет |
|---|---|
| простой текст (example.com) | первый экран ≤ 0.8 с |
| текстовая статья (Wikipedia) | полностью ≤ 2.5 с |
| плотная страница (HN, DDG) | ≤ 3 с |
| сложная (GitHub, habr) | ≤ 8 с |
| SPA-оболочка (YouTube) | либо контент ≤ 10 с, либо честная заглушка |
| прокрутка | 60 fps, без «залипаний» > 100 мс |
| память | 5 вкладок ≤ 500 МБ, без роста при повторных переходах |

Измерять по фазам (сеть / парсинг / CSS / раскладка / отрисовка / JS) и
печатать в `--stats`, иначе оптимизация — угадывание.

## 11. Устойчивость

- Кривой HTML/CSS/JS не роняет процесс: ошибка → страница-объяснение, а не
  паника.
- Повторные переходы туда-обратно не течут памятью (замер RSS до/после).
- Сеть пропала — сообщение и «повторить», кнопка «назад» работает.
- Битые картинки/шрифты не ломают раскладку.
- Процесс не висит на одном сайте, остальные вкладки живы.

## 12. Доступность (минимум)

Клавиатурная навигация по ссылкам/полям, видимый фокус, `Tab`/`Shift+Tab`,
`Enter`/`Space` на кнопках, масштаб до 200% не ломает вёрстку, контраст
текста как у сайта.

## 13. Матрица совместимости

Не три сайта. Минимум 30, по категориям; для каждого — оценка `scripts/qa.py`
(функции) и `scripts/visual-diff.py` (сходство с оригиналом):

- текст/новости: Wikipedia, habr, lenta.ru, rbc.ru, medium
- форумы: Hacker News, reddit, stackoverflow, users.rust-lang.org
- документация: docs.rs, developer.mozilla.org, python.org
- магазины: ozon.ru, wildberries.ru, aliexpress, amazon
- SPA: github, youtube, x.com, vk.com
- медиа: youtube watch, rutube, soundcloud
- гос/банки: gosuslugi.ru, sberbank.ru (только открытие)
- простые: example.com, DDG lite

Порог приёмки: **средняя функциональная оценка ≥ 85%**, ни одного «чёрного
экрана», и сходство с оригиналом: example ≥ 80, Wikipedia ≥ 60, GitHub ≥ 55.

## 14. Чего в этом этапе нет (и не должно появиться)

- анонимность, цепочки, killswitch, DoH-политики — моя часть, позже;
- профили, персоны, подмена языка по exit-IP, «Паспорт», «Трафик», «Сжечь»;
- собственный док вместо вкладок, свои меню вместо стандартных;
- автоматический переход на чужой движок, подмена сайтов сгенерированными
  страницами;
- «умные» стартовые страницы вместо пустой вкладки (пустая — стандарт).

Если что-то из этого нужно для работы сайта (например, WebKit), это
обсуждается отдельно и явно, а не включается молча.

## 15. Порядок работ

| Этап | Что | Приёмка |
|---|---|---|
| M1 | текст и ссылки | Wikipedia/HN/DDG читаются, ссылки кликаются, ≤ 3 с |
| M2 | раскладка | сайдбар и инфобокс Wikipedia, таблица и About GitHub, нет обрезки справа |
| M3 | формы и ввод | поиск на сайте, вход в форму, POST работает |
| M4 | JS-платформа | shell YouTube: customElements, performance, observers; кнопки с onclick/listener |
| M5 | вкладки и Chrome | `⌘T/W/R/L/F`, контекстное меню, масштаб, история назад/вперёд |
| M6 | скачивания и медиа | файл качается, видео играет, звук есть |
| M7 | производительность | бюджеты из §10 по фазам |
| M8 | матрица 30 сайтов | пороги §13 на всех |

Каждый этап: механизм + регрессионный тест + цифры до/после на 3+ сайтах.

## 16. Формат отчёта

Не «починил сайт X». А:

```
механизм: display: table / колонки grid
сайты:    github 37.7 → 48.2, wikipedia 41.7 → 44.0
тесты:    +N регрессий в layout/css
осталось: sticky шапки, column-gap
```

И список «чего ещё нет» в `docs/COMPATIBILITY.md`, чтобы общие дыры были
видны, а не растворялись в отчётах о победах.

## 17. Инструменты проверки (мои, не твои)

- `python3 scripts/qa.py` — функции: текст, ссылки, клик, пиксели, время.
- `python3 scripts/visual-diff.py --url …` — сходство с эталоном Chrome:
  композит «эталон | наш | пропало/лишнее», score, полосы.
- `browser/target/release/sepia-browser --audit` — фактическая поверхность.
- `docs/QA.md` — базовая линия и ручной чек-лист.

Эти инструменты — внешняя правда. Если твоя правка не подняла их цифры, она
не считается сделанной.
